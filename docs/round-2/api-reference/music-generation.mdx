# Sinh nhạc (Lyria 3)

## <Badge method="POST" /> `/audio/speech`

Sinh một bản nhạc từ mô tả bằng chữ. Dùng chung endpoint với Text-to-Speech, khác ở tên model.
:::info[Tham khảo]
Hướng dẫn chi tiết và cách viết prompt: [Sinh nhạc với Lyria 3](../user-guide/music-generation-lyria.mdx). Tài liệu gốc: [Lyria 3 (Google)](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/lyria/lyria-3).
:::

<ApiReferenceLayout>
  <LeftColumn>
    ### Cấu trúc yêu cầu (Request Body)

    <ApiParameter name="model" type="string" required>
      `lyria-3-clip-preview` (bài khoảng 30 giây, $0.04) hoặc `lyria-3-pro-preview` (bài khoảng 3 phút, $0.08).
    </ApiParameter>
    <ApiParameter name="input" type="string" required>
      Mô tả bản nhạc: thể loại, tâm trạng, nhạc cụ, nhịp độ, giọng hát, lời bài hát.
    </ApiParameter>
    <ApiParameter name="voice" type="string" required>
      Lyria không dùng giọng đọc. Gửi `default`.
    </ApiParameter>
    <ApiParameter name="response_format" type="string" isEnd>
      `mp3` (mặc định). Riêng `lyria-3-pro-preview` nhận thêm `wav`.
    </ApiParameter>

    ---

    ### Cấu trúc Phản hồi (Response Body)

    Phản hồi thành công trả về file âm thanh (`audio/mpeg`). Header `x-litellm-response-cost` cho biết chi phí của request.

    ### Lỗi thường gặp

    <ApiParameter name="429" type="rate limit" isEnd>
      Vượt 105 request/phút của model đó, hoặc hết budget.
    </ApiParameter>

  </LeftColumn>
