# Sinh video (Bước 1/3): Bắt đầu tác vụ
:::info[Thông tin]
API video tuân theo chuẩn [OpenAI Videos API](https://platform.openai.com/docs/api-reference/videos). Chi tiết về mô hình Veo, xem tại [tài liệu của Google Vertex AI](https://cloud.google.com/vertex-ai/generative-ai/docs/models/veo/3-1-generate).
:::

:::warning[Chi phí]
Video được tính tiền **theo số giây** ngay khi tác vụ được tạo:
- `veo-3.1-generate-001`: $0.40 / giây
- `veo-3.1-fast-generate-001`: $0.10 / giây (720p), $0.12 / giây (1080p), $0.30 / giây (4K)
- `veo-3.1-lite-generate-001`: $0.05 / giây (720p), $0.08 / giây (1080p)

Ví dụ: một video 8 giây bằng `veo-3.1-generate-001` tốn $3.20.
:::

## <Badge method="POST" /> `/v1/videos`

Gửi một yêu cầu chứa mô tả (prompt) để bắt đầu quá trình tạo video. API trả về `id` của video để bạn theo dõi trong các bước tiếp theo.

<ApiReferenceLayout>
  <LeftColumn>
    ### Cấu trúc yêu cầu (Request Body)

    <ApiParameter name="model" type="string" required>
      Mô hình sẽ sử dụng để tạo video:
        - `veo-3.1-generate-001`: chất lượng cao nhất
        - `veo-3.1-fast-generate-001`: nhanh hơn, rẻ hơn
        - `veo-3.1-lite-generate-001`: rẻ nhất
    </ApiParameter>
    <ApiParameter name="prompt" type="string" required>
      Mô tả chi tiết về video cần tạo.
    </ApiParameter>
    <ApiParameter name="seconds" type="string">
      Thời lượng video: `"4"`, `"6"` hoặc `"8"`. Mặc định là `"8"`.
    </ApiParameter>
    <ApiParameter name="size" type="string">
      Kích thước video, quyết định tỷ lệ khung hình và độ phân giải:
      - `"1280x720"` (16:9, 720p, mặc định), `"1920x1080"` (16:9, 1080p)
      - `"720x1280"` (9:16, 720p), `"1080x1920"` (9:16, 1080p)
    </ApiParameter>
    <ApiParameter name="input_reference" type="file" isEnd>
      Ảnh khởi đầu để tạo video từ ảnh (image-to-video). Khi có trường này, gửi request dạng `multipart/form-data` thay vì JSON. Xem ví dụ ở [hướng dẫn tạo video](../user-guide/video-generation-veo3).
    </ApiParameter>

    ---

    ### Cấu trúc Phản hồi (Response Body)

    <ApiParameter name="id" type="string">
      ID của video. Dùng giá trị này để kiểm tra trạng thái ở [Bước 2](./video-generation-status) và tải video ở [Bước 3](./video-generation-download).
    </ApiParameter>
    <ApiParameter name="status" type="string" isEnd>
      Trạng thái tác vụ, ban đầu là `processing`.
    </ApiParameter>
