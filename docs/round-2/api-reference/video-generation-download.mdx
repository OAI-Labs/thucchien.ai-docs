# Sinh video (Bước 3/3): Tải video

## <Badge method="GET" /> `/v1/videos/{video_id}/content`

Khi `status` ở Bước 2 là `completed`, dùng cùng `id` đó để tải file video về.

<ApiReferenceLayout>
  <LeftColumn>
    ### Tham số đường dẫn (Path Parameters)
    <ApiParameter name="video_id" type="string" required isEnd>
      `id` của video nhận được ở [Bước 1](./video-generation-start).
    </ApiParameter>

    ---

    ### Phản hồi (Response)
    Phản hồi thành công là dữ liệu video `video/mp4`. Nếu video chưa tạo xong, API trả về lỗi.
  </LeftColumn>
  <RightColumn>
