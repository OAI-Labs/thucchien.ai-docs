# Đọc lại AI Log

## <Badge method="GET" /> `/api/ingest/entries`

Trả về các dòng log AI mà đội đã gửi lên (qua `scripts/submit_log.py` hoặc pre-push hook), mới nhất trước. Dùng để kiểm tra log đã lên đủ và đúng chưa. Cách cài đặt và gửi log xem [Cấu hình AI Log](../ai-log-guide.mdx).

:::warning[Khác host, khác key]
API này chạy trên **`https://live.thucchien.ai`** và xác thực bằng **token `aitc_...`** của đội (biến `AI_LOG_API_KEY` trong `.env`), **không phải** key Gateway `api.thucchien.ai` dùng ở các trang khác trong mục này. API chỉ trả log của đội sở hữu token.
:::

<ApiReferenceLayout>
  <LeftColumn>
    ### Headers

    <ApiParameter name="Authorization" type="string" required isEnd>
      `Bearer <AI_LOG_API_KEY>`, token bắt đầu bằng `aitc_` BTC cấp cho đội.
    </ApiParameter>

    ---

    ### Tham số query

    <ApiParameter name="limit" type="integer">
      Số dòng mỗi trang. Mặc định `50`, tối đa `200`.
    </ApiParameter>
    <ApiParameter name="before" type="string">
      Chỉ lấy log có `ts` trước thời điểm này (ISO 8601). Dùng để lấy trang tiếp theo: truyền giá trị `next_before` của trang trước, giữ nguyên các tham số khác.
    </ApiParameter>
    <ApiParameter name="event" type="string">
      Lọc theo tên event, khớp chính xác (ví dụ `UserPromptSubmit`, `PostToolUse`). Để trống là không lọc.
    </ApiParameter>
    <ApiParameter name="tool" type="string" isEnd>
      Lọc theo công cụ, không phân biệt hoa thường (ví dụ `claude`, `cursor`, `codex`). Để trống là không lọc.
    </ApiParameter>

    ---

    ### Cấu trúc phản hồi (Response Body)

    <ApiParameter name="items" type="array">
      Các dòng log, mới nhất trước.
    </ApiParameter>
    <ApiParameter name="next_before" type="string | null" isEnd>
      Khác `null` khi còn trang sau; truyền vào `before` để lấy tiếp.
    </ApiParameter>

    #### Mỗi phần tử trong `items`

    <ApiParameter name="ts" type="string" indent={2}>
      Thời điểm event diễn ra (UTC, ISO 8601).
    </ApiParameter>
    <ApiParameter name="received_at" type="string" indent={2}>
      Thời điểm hệ thống nhận dòng log.
    </ApiParameter>
    <ApiParameter name="tool" type="string" indent={2}>
      Công cụ AI, đã chuyển về chữ thường.
    </ApiParameter>
    <ApiParameter name="event" type="string" indent={2}>
      Tên event gốc của công cụ.
    </ApiParameter>
    <ApiParameter name="session_id" type="string" indent={2}>
      Mã phiên làm việc.
    </ApiParameter>
    <ApiParameter name="model" type="string" indent={2}>
      Tên model nếu công cụ cung cấp.
    </ApiParameter>
    <ApiParameter name="repo, branch, commit, student" type="string" indent={2}>
      Thông tin git lúc ghi log.
    </ApiParameter>
    <ApiParameter name="prompt" type="string" indent={2}>
      Nội dung prompt (với event prompt).
    </ApiParameter>
    <ApiParameter name="tool_name, tool_input, tool_response, tool_error" type="string / object" indent={2}>
      Tool AI đã gọi, input, output và lỗi (với event gọi tool).
    </ApiParameter>
    <ApiParameter name="response_summary, stop_reason" type="string" indent={2} isEnd>
      Câu trả lời cuối lượt và lý do dừng (với event kết thúc lượt).
    </ApiParameter>

    Trường không có giá trị trả về `null`. Các trường dài đã bị cắt theo giới hạn như lúc lưu.

    ---

    ### Mã lỗi

    <ApiParameter name="401" type="unauthorized" isEnd>
      Thiếu token hoặc token sai. Đội đã bị khoá bảng đấu **vẫn đọc được**; khoá chỉ chặn gửi log mới.
    </ApiParameter>
